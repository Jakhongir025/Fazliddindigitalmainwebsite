# Fazliddin Digital — Telegram arizalari

Mahalliy: loyiha ildizidagi yopiq .env.local faylida TELEGRAM_BOT_TOKEN va TELEGRAM_CHAT_IDS saqlanadi. IDlar vergul bilan, 1–5 shaxsiy chat. Har bir qabul qiluvchi botga Start bosishi kerak. Qiymatlarni GitHubga yuklamang. npm run demo orqali sayt va API birga ishlaydi (Node 22).

Vercel: Settings → Environment Variables → Production ichiga shu ikki nom va qiymatlarini alohida kiriting, keyin Redeploy qiling. Domen o‘zgarsa SITE_ORIGIN sozlanishi mumkin. Google Sheets, Apps Script va Upstash kerak emas. Yetkazish va takroriy so‘rov himoyasi server instansiyasi ichida ishlaydi; instansiyalar orasida doimiy kafolat yo‘q. Meta sozlamalari META-ULASH.md da.
